0.99 ~ 1.00

开盘 / 收盘 / 最高 / 最低 四列互为近完全相关。这属于结构性必然——它们同日同源，不是独立信息，不能据此得出"价格互相影响"的结论。

0.95

成交额与换手率高度相关。成交额 ≈ 均价 × 成交量、换手率 ≈ 成交量 ÷ 流通股本，两者共同由成交量驱动，同样存在口径上的共线。

0.34 ~ 0.36

成交量与价格水平的相关系数仅 0.34 左右，是矩阵中少数非冗余的信息：放量并不等于高价，量价关系需单独分析。

结论

01

四年走完一个完整周期，累计收益近乎归零

2023-01-03 收盘 {{ fmt(kpi.first_close) }} 元，{{ meta.end }} 收盘 {{ fmt(kpi.last_close) }} 元， 累计 {{ pct(kpi.total_return_pct) }}。但期间最高 {{ fmt(kpi.high.value) }} 元、最低 {{ fmt(kpi.low.value) }} 元， 振幅 {{ pct((kpi.high.value / kpi.low.value - 1) * 100) }}。终点回到起点，过程却极不平坦。

02

波动与回撤是这只票的主要风险来源

年化波动率 {{ kpi.ann_vol_pct }}%，最大回撤 {{ kpi.max_drawdown_pct }}%。 对持有者而言，收益的不确定性远大于收益本身；仅看累计涨幅会严重低估持有体验的恶化程度。

03

相关系数矩阵里真正有信息量的格子很少

价格四列之间 0.99 以上、成交额与换手率 0.95，都是口径决定的结构性相关。 真正值得看的是成交量与价格的 0.34——量价并不同步，放量不等于上涨，这为后续做量价背离分析留出了空间。

04

2023 年 4–6 月是一段无趋势的箱体震荡

区间涨跌 {{ pct(kline.chg_pct) }}，涨跌天数 {{ kline.up_days }}: {{ kline.down_days }} 接近均衡，高低点相距 {{ pct((kline.high.value / kline.low.value - 1) * 100) }}。 6 月中旬的放量突破未能延续，说明当时的量能不足以支撑趋势反转。
