## 五、主要结论

1. 2023-01-03 至 2026-11-04，收盘价从 261.73 元到 266.62 元，**累计仅 +1.87%**，但期间最高 410.49 元、最低 169.40 元，最大回撤 **-44.56%**。
2. 年化波动率 30.75%。收益的不确定性远大于收益本身。
3. 相关系数矩阵中价格四列之间 0.99+、成交额与换手率 0.95，都是**口径决定的结构性冗余**，不构成独立信息；真正有解释力的是成交量与价格的 0.34。
4. 2023 年 4–6 月为无趋势箱体震荡，区间涨跌 +0.91%，涨跌天数 26:33，6 月中旬放量突破未能延续。

## 六、口径声明

- 价格为**后复权**，单位为元；后复权以基准日调整后续价格，历史价不随新分红变动，适合计算长期收益率与走势比较。
- 成交量单位为**手**（1 手 = 100 股）。
- 振幅、涨跌幅、换手率单位为 **%**，数据本身已是百分数，未再乘 100。
- 本页为课程作业的数据分析演练，**不构成任何投资建议**。
