# 比亚迪（002594.SZ）股票价格走势分析与可视化

> 教材 P92 实战演练 · 移动端 H5 静态页面
> 数据区间：2023-01-03 ~ 2023-12-29 ｜ 242 个交易日 ｜ 后复权

一个**零构建、零网络、可离线双击打开**的移动端数据分析页面：先用 Python 把行情数据算成结构化指标，
再用 Vue 3 + TDesign Mobile Vue + ECharts 把「分析过程」与「可视化结果」渲染成一个 5 屏的移动端报告。

---

## 快速开始

```bash
# 1. 生成数据（可选，仓库内已包含生成结果）

# 2. 打开页面
#    直接双击 site/index.html 即可，无需任何服务器
```

## 核心结论

| # | 结论 | 关键指标 |
|---|---|---|
| 1 | 跌幅分两段，全年并非单边下行 | 2/01→3/16 **-22.76%**；7/31→12/20 **-31.75%**；中间夹 92 天 +16.25% 的修复 |
| 2 | 下半场贡献了全部跌幅 | H1 **+4.21%** → H2 **-26.53%** |
| 3 | 回撤远大于跌幅 | 区间 -23.43%，最大回撤 **-38.71%**（12-20 见底） |
| 4 | 跌多于涨，但反弹弹性更强 | 涨 102 天 / 跌 140 天，胜率 **42.15%**；最大单日 +6.46% > 最大单日 -5.18% |
| 5 | 量价脱钩，跌得久但不是放量砸 | 换手率 × 涨跌幅 r = **0.227**；下跌日中 **75%** 为缩量下跌 |
| 6 | 波动即流动性 | 成交额 × 振幅 r = **0.713**，唯一强相关 |

## 指标口径

| 指标 | 定义 |
|---|---|
| 年化波动率 | 日对数收益标准差 × √252 |
| 最大回撤 | `收盘 / 历史最高收盘 − 1` 的最小值 |
| 夏普比率 | `(年化收益 − 2%) / 年化波动`，无风险利率取 2% |
| 量比 20 | `当日成交量 / 过去 20 日均量`，用于划分放量 / 缩量 |
| 走势阶段 | ZigZag 拐点法，反向幅度阈值 **10%** |
| 日胜率 | `上涨天数 / (上涨 + 下跌)` |
| 月度收益 | `月末收盘 / 上月末收盘 − 1`（首月以首日收盘为基） |

## 数据体检

| 项 | 结果 |
|---|---|
| 原始规模 | 242 行 × 11 列 |
| 缺失值 | 0 |
| 重复日期 | 0 |
| OHLC 逻辑冲突 | 0 |
| 非正价格 / 零成交 | 0 / 0 |

**一个额外发现**：`换手率 / 成交量` 的变异系数仅 **0.35%**，说明数据期内流通股本视为恒定，
换手率与成交量互为线性映射。因此在相关性分析与散点图中二者只取其一，避免同一信息被重复计数。

## 设计说明

- **品牌色与涨跌语义解耦**：品牌用冷调金融蓝（`#1F3A5F`），涨跌沿用 A 股红绿（`#D5493F` / `#17935E`）。
  若品牌色也用红，页面里就会出现两种「红」，读者无法判断哪个代表上涨。
- **图表跟着数据形状走**：四价用蜡烛图、多序列趋势用折线、离散周期用柱状、相关性用散点、深度用面积图。
- **每个结论必须带证据**：洞察卡片底部的标签是支撑该结论的指标值，可直接在「统计」页核对。
