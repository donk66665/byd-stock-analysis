### 考核点 2 · 使用 ui-ux-pro-skill 做设计，移动端展示过程与结果（h5 静态页面）

**技能使用**

- 技能：`ui-ux-pro-max`（UI/UX 设计智能引擎）
- 调用方式：`generate` 生成设计系统 + `charts` 检索图表选型
- 生成结论：Data/Dashboard 风格、Calm Triadic 013 调色板、Inter 字体、正文对比度 16.53:1

**设计系统落地**

| 维度 | 生成结论 | 落地调整 |
|---|---|---|
| 风格 | Data / Dashboard | 采用；卡片 + 紧凑网格 + sticky 头部 |
| 配色 | primary `#4475A7`、bg `#F6F7F9`、text `#16181D` | 保留；**追加** A 股语义色 涨 `#D5493F` / 跌 `#17935E`，品牌色与涨跌语义解耦 |
| 字体 | Inter | 采用；本地 woff2 子集，中文回退系统栈 |
| 图表 | Candlestick / Area / Bar / Scatter | 采用，按数据形状分配 |
| 反模式 | 信息过载、低对比度数据 | 规避：5 屏分段承载、正文 ≥ 12px、图表刻度 ≥ 9px |

**「过程」与「结果」双展示**

| 维度 | 所在 Tab | 内容 |
|---|---|---|
| 过程 | 过程 | 5 步流程条 + 逐步拆解（可折叠，含真实代码）+ 数据体检报告 + 指标口径表 + 图表选型对照表 |
| 结果 | 概览 / 走势 / 统计 / 结论 | 6 项 KPI、7 张图表、4 阶段明细、量价四象限、6 条洞察 |

**静态页面**：`site/index.html`，无构建、无网络、双击即开。

### 考核点 3 · 使用 TDesign 做 UI 控件

**前提说明**：本地 Connector 市场未提供 TDesign MCP 服务，且 MCP 需重启客户端才能生效，
无法在本次会话内接入。故改为**直接接入 TDesign 官方组件库本体**（`tdesign-mobile-vue@1.11.0`），
并通过解析 UMD 导出表确认可用 89 个组件，从中选用 13 个。

MCP 的产物本就是 TDesign 组件代码，本例通过直接读取组件库源码与渲染 DOM 来确认 API，产出等价。

**实际使用的 TDesign 组件**

| 组件 | 用途 | 出现位置 |
|---|---|---|
| `t-tabs` / `t-tab-panel` | 5 屏主导航（sticky） | 全局 |
| `t-steps` / `t-step-item` | 5 步分析流程 | 过程 |
| `t-collapse` / `t-collapse-panel` | 方法细节折叠展开 | 过程 |
| `t-cell-group` / `t-cell` | 数据体检、制作说明 | 过程 / 结论 |
| `t-tag` | 阶段标签、涨跌状态 | 概览 / 过程 |
| `t-check-tag` | K 线区间切换 | 走势 |
| `t-progress` | 冗余系数占比条 | 过程 |
| `t-notice-bar` | 口径说明、风险提示 | 概览 / 结论 |
| `t-popup` | 图表全屏查看 | 全局 |
| `t-button` | 弹层收起 | 全屏弹层 |
| `t-back-top` | 回到顶部 | 全局 |
